# Lueur 店舗LP 設計書(ブリーフ)

> ※ Lueur は、LPテンプレート横展開のデモ用に作成した**架空の美容室**です。店舗・スタッフ・お客様の声などはすべて架空の内容です。

## 1. ブランド

| 項目 | 内容 |
|---|---|
| 店名 | Lueur(リュウール) |
| 名前の意味 | フランス語で「ほのかな光」 |
| コンセプト | 毎日の髪に、ほのかな光を。 |
| 一番の強み | 髪質改善トリートメントで、手入れに時間をかけなくてもツヤが続く髪へ |
| 雰囲気 | ナチュラル・やわらか(ベージュ・白・木の質感、やさしい光) |

## 2. ターゲット(ペルソナ)

| 項目 | 内容 |
|---|---|
| 年代・属性 | 20〜30代の働く女性 |
| 生活 | 平日は仕事で忙しく、朝のスタイリングにかけられる時間は10分ほど |
| 髪の悩み | パサつき・広がり・ツヤがない。カラーを繰り返して髪が傷んできた |
| 美容室に求めること | 仕事帰りや休日に通いやすい。家でも再現しやすい。落ち着いて過ごせる |
| 予約の決め手 | ビフォーアフターのイメージ、料金の分かりやすさ、アクセス、営業時間 |

## 3. LPの構成

「共通」は全店舗で同じ内容、「店舗別」は店舗ごとに差し替える内容です。

| # | セクション | 目的 | 共通/店舗別 |
|---|---|---|---|
| 1 | ファーストビュー | ひと目で「ツヤ髪になれる、通いやすいお店」と伝える | キャッチは共通、サブコピー・店舗名・写真は**店舗別** |
| 2 | お悩み | 「私のことだ」と共感してもらう | 共通 |
| 3 | Lueurの髪質改善(強み) | 選ばれる理由を3つで伝える | 共通 |
| 4 | メニュー・料金 | 料金の分かりやすさで安心してもらう | 共通 |
| 5 | 施術の流れ | 初めてでも不安なく来店できるように | 共通 |
| 6 | スタッフ紹介 | 担当してくれる人が見えて安心 | **店舗別** |
| 7 | お客様の声 | 実際の変化をイメージしてもらう | **店舗別** |
| 8 | よくある質問 | 予約前の疑問を解消 | 共通 |
| 9 | 店舗情報・アクセス | 通いやすさを伝える | **店舗別** |
| 10 | 予約 | 迷わず予約に進んでもらう(各セクションの後にも予約ボタン) | 予約先は**店舗別** |

## 4. 各セクションの内容(下書き)

### 1. ファーストビュー
- キャッチ(共通):**毎日の髪に、ほのかな光を。**
- サブコピー(店舗別):例)「渋谷駅から徒歩3分。仕事帰りの21時まで。」
- ボタン:「この店舗で予約する」

### 2. お悩み(共通)
- 朝は時間がなくて、髪の手入れまで手が回らない
- カラーを繰り返して、毛先のパサつきが気になる
- 雨の日は広がって、まとまらない
- サロン帰りはきれいなのに、数日で元に戻ってしまう

### 3. Lueurの髪質改善 — 選ばれる3つの理由(共通)
1. **髪の状態に合わせたオーダーメイドのケア**:毎回、髪の状態を見てから薬剤と工程を決めます
2. **ツヤが続く、おうちケアの提案**:忙しい朝でも続けられる、簡単なケア方法をお伝えします
3. **一人ひとりに向き合う落ち着いた空間**:担当スタイリストが最初から最後まで対応します

### 4. メニュー・料金(共通・税込・架空の価格)
| メニュー | 料金 |
|---|---|
| 髪質改善トリートメント | 11,000円 |
| カット+髪質改善トリートメント | 16,500円 |
| カット+カラー+髪質改善トリートメント | 22,000円 |
| カット | 6,600円 |
| 初回限定:カット+髪質改善トリートメント | 13,200円 |

### 5. 施術の流れ(共通)
カウンセリング → 髪の状態の診断 → 施術 → 仕上がりの確認 → おうちケアのご提案

### 6. スタッフ紹介(店舗別)
店長1名+スタイリスト1名。名前・経歴・得意なこと・ひとこと

### 7. お客様の声(店舗別・架空)
2〜3件。年代・職業・来店前の悩み・来店後の変化

### 8. よくある質問(共通)
- 施術時間はどのくらいですか?
- 効果はどのくらい続きますか?
- カラーと同じ日にできますか?
- 当日予約はできますか?

### 9. 店舗情報・アクセス(店舗別)
住所・最寄り駅からの道順・営業時間・定休日・地図

## 6. 表現で気をつけること

- 美容の広告では、効果を言い切る表現(「必ず」「絶対」「治る」など)は使わない
- 「ツヤが出る」「まとまりやすくなる」など、体験として伝える表現にする
- 料金は税込で表示する
